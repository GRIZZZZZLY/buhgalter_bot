# Telegram Finance Bot WebApp

## UI/UX plan

1. **Hero treasury card**
   - Крупный баланс месяца
   - Доход / расход рядом, но вторично
   - Лёгкий древнерусский декоративный слой: рамка, орнамент, благородные цвета

2. **Period switch**
   - Сегодня / Неделя / Месяц / Всё
   - Как сегмент-контрол, максимально touch-friendly

3. **Category analytics**
   - Donut chart + легенда карточками
   - Акцент на читаемости, не на спецэффектах

4. **Recent transactions ledger**
   - Список как современная летопись операций
   - Сумма, категория, время, компактный secondary text

5. **Edit bottom sheet**
   - Современный mobile-first sheet
   - Декор минимальный, контроль максимальный

6. **Empty states**
   - Спокойные, чистые, без клоунады
   - Вайб незаполненной летописи, но читаемый продуктовый UX

## Stack
- React
- TypeScript
- Vite
- Telegram WebApp ready structure
