# Frontend V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a new Telegram Mini App V2 that covers the current product scope with a workspace-first mobile architecture.

**Architecture:** Keep the existing React 19 + Vite + `@tma.js/sdk-react` stack, but reorganize the frontend around product domains instead of a small dashboard app. Delivery is phased: first shared shell and core screens, then product-parity domains, then polish.

**Tech Stack:** React 19, TypeScript, Vite, `@tma.js/sdk-react`, TanStack Query, Tailwind v4, shadcn-style primitives, Motion, Zod.
